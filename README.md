# Files for RNG manipulation with emulators
Completed save files for Pokémon Platinum and HeartGold/SoulSilver

File 'Platine.dsX.' contains a streak in the battle factory of round X

Lua scripts are included to display the seed and frame

Requires the following:

  -An Emulator; [DeSmuME](https://desmume.org/), [Bizhawk](https://tasvideos.org/Bizhawk), [melonDS](https://melonds.kuribo64.net/)
  
  -A Pokémon Platinum ROM; [Platine](https://www.emulatorgames.net/roms/nintendo-ds/pokemon-version-platine-fr/)

  -A Pokémon SoulSilver ROM; [SoulSilver](https://www.emulatorgames.net/roms/nintendo-ds/pokemon-soulsilver-version/)

  -A save editor; [PKHeX](https://projectpokemon.org/home/files/file/1-pkhex/)
