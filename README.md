# Files for RNG manipulation with emulators
Completed save files for Pokémon Platinum and HeartGold/SoulSilver

Files 'Platine.dsX' and 'Platine.mlX' contain a streak in the battle factory of round X

Lua scripts are included to display the seed and frame in DeSmuME

Requires the following:

  -An Emulator; [DeSmuME](https://desmume.org/), [melonDS](https://melonds.kuribo64.net/)
  
  -[Pokémon Platinum ROM](https://www.emulatorgames.net/roms/nintendo-ds/pokemon-version-platine-fr/)

  -[Pokémon SoulSilver ROM](https://www.emulatorgames.net/roms/nintendo-ds/pokemon-soulsilver-version/)

  -[Pokémon Renegade Platinum patch](https://projectpokemon.org/home/forums/topic/52294-pok%C3%A9mon-renegade-platinum/); [wiki](https://fredericdlugi.github.io/platinum-renegade-wiki/)

  -A save editor; [PKHeX](https://projectpokemon.org/home/files/file/1-pkhex/)

  -An RNG tool; [PokéFinder](https://github.com/Admiral-Fish/PokeFinder/releases)

  -A timer; [EonTimer](https://github.com/DasAmpharos/EonTimer/releases)

To check the seed in melonDS, have a DeSmuME with lua script in the title screen to display the current seed, click continue on melonDS, and verify the seed with PokeFinder using Coin Flips and Chatter
